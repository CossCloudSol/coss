# My Blog

This Next.js site was generated by [LeaveWP](https://leavewp.com) from https://nextjs.cosscloudsol.com/.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deploy to Vercel

The easiest way to deploy is with [Vercel](https://vercel.com):

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=YOUR_REPO_URL)

## Project Structure

```
├── src/
│   ├── app/              # Next.js App Router pages
│   ├── components/       # Reusable components
│   └── lib/              # Utility functions
├── content/
│   ├── posts/            # Blog posts (MDX)
│   └── pages/            # Static pages (MDX)
├── public/               # Static assets
└── package.json
```

## Customization

- Edit `src/app/globals.css` for styling
- Modify `tailwind.config.ts` for theme colors
- Update `src/app/layout.tsx` for site metadata
